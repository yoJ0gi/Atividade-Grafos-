Trabalho da disciplina de grafos. Implementamos o grafo de três formas diferentes, usando como base os esqueletos passados pelo professor:

- lista_adjacencia.py: lista de adjacência
- matriz_adjacencia.py: matriz de adjacência
- lista_arestas.py: lista de arestas

Cada arquivo funciona sozinho e tem o mesmo menu: inserir e remover vértices e arestas, ver se uma aresta existe, listar vizinhos, mostrar os graus e testar um percurso.

## Como rodar

Só precisa do Python 3:

## python3 lista_adjacencia.py


Para rodar os outros, é só trocar o nome do arquivo.

Ao abrir, o programa pergunta se o grafo é direcionado ou não e já começa com um exemplo com os vértices A, B, C e D.
